# Nautica Marine & Fleet Operations System - Navlakhi Station

Comprehensive Marine Operations, Crew Attendance, Fleet Dispatch, and Historical Leave Ledger System for Navlakhi Port.

## Features
- **Daily Attendance Marking:** Clock In/Out, Present, Leave, On Sea, and Marina Pier Zones.
- **Crew Roster & Leave Ledger:** Track total days worked, approved rotational leaves, and reporting dates since joining date.
- **Excel (.xlsx / .csv) Export:** Full individual and master station attendance ledger exports with UTF-8 BOM encoding.
- **Maritime Safety Audit:** Correction requests flow to Admin with safety warning protocols.
- **Bilingual Interface:** Instant one-click toggle between Tamil (தமிழ்) and English.
- **3D Digital Twin Basin & AIS Radar:** Interactive 3D fleet harbor view and live coastal vessel tracking.

## Getting Started
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
